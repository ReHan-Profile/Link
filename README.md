# Rehan – Personal Profile Website

A personal profile website for **Rehan**, built as a fast, single-page site with no build step and no dependencies to install.

**Live site:** https://rehan-profile.github.io/Link/

## Features

- Rotating name display in English and Urdu, with an animated entrance.
- Animated profile figure that walks in and waves.
- Scrolling strip of professional roles.
- Social media buttons for all major platforms (links are set in `links.js`).
- Three pages: **Rehan** (profile), **Games** and **Tools**.
- **AeroCutter & Joiner Pro**: an audio cutter, joiner and voice-effects tool that runs entirely in the browser. Files stay on the user's device and are never uploaded.
- Responsive layout for phones and laptops.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | The website (pages, styling and behaviour) |
| `links.js` | Social media links, edit this file to add or change links |
| `aerocutter.html` | The AeroCutter & Joiner Pro audio tool |
| `rehan-walk.webp` | The animated profile figure |

## Updating social links

Open `links.js`, write the full link for each platform between the quotation marks and commit the change. Leave a link empty (`""`) if it is not available yet. For WhatsApp use `https://wa.me/` followed by the number with the country code, without a plus sign or spaces.

## Running locally

Download all the files into one folder and open `index.html` in a browser.
